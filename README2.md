# Adaptive Neural Automaton (ANA) v2: Self-Bootstrapping Recursive Architecture

## Overview

The Adaptive Neural Automaton (ANA) v2 extends the original ANA framework by introducing a fundamental breakthrough in self-modifying neural architectures. Unlike traditional state-space models (SSMs) or transformers that rely on fixed parameters or adaptive but non-recursive dynamics, ANA v2 enables **recursive self-definition** through a differentiable program stack. This allows the model to bootstrap its own computational rules mid-sequence, inventing higher-order abstractions from minimal examples.

Key innovations:
- **Differentiable Program Stacks**: A finite-depth stack (max 5 frames) for recursive rule composition, enabling emergent modularity without infinite unrolling.
- **Live Interpreter with Crisp Opcodes**: A meta-state that acts as an interpreter, executing discrete operations on parallel tracks via Gumbel-Softmax for differentiability.
- **Fault-Trace Holographic Persistence**: A self-correcting memory mechanism that stores and retrieves error patterns to refine rules on-the-fly, promoting dense, few-shot learning.

Theoretical foundation: Builds on vector symbolic architectures (VSAs) for binding, linear RNNs for efficiency, and meta-learning for self-modification. The result is a system capable of programmatic adaptation—e.g., deriving subtraction from addition examples in one exposure—while maintaining linear-time complexity (O(N) per sequence).

Advantages:
- **Breakthrough Capacity**: Combinatorial rule composition yields exponential expressivity in finite parameters (~50M total).
- **Dense Learning**: Programmatic updates enable one-shot generalization; fault traces ensure self-correction without massive datasets.
- **Scalability**: Parallel tracks and stack operations fit on single GPUs; inference remains sub-linear via caching.

Target Benchmarks:
- Perplexity: <25 on WikiText-103 (100M params), surpassing Mamba by 8+ points.
- Associative Recall: 99% on 50-fact chains, no degradation.
- Emergent Capabilities: 100% accuracy on unseen logic tasks (e.g., modulo from addition) post one-shot exposure.

This specification is designed as a pursuable research agenda: modular, testable, with staged implementation to mitigate risks like gradient instability.

## Architecture

ANA v2 processes sequences token-by-token, evolving a hidden state across parallel tracks under rules defined by a self-modifying meta-state. The meta-state is a stack-based interpreter that recursively refines itself.

### Components

1. **Parallel Tracks**:
   - Three specialized state vectors (evolved in parallel via associative scans for O(N) efficiency):
     - **Syntax Track**: Short-term, fast-decay (dim=64) for local patterns (e.g., grammar).
     - **Semantic Track**: Long-range, slow-decay (dim=128) for concepts and bindings.
     - **Logic Track**: Scratchpad (dim=64) for discrete operations (e.g., math, reasoning).
   - Total state dim: ~256. Updates via linear recurrence: \( h_{t+1} = A h_t + B x_t \), where A/B are generated by the interpreter.

2. **Meta-State Stack**:
   - Finite stack (max depth=5) to prevent explosion; each frame: 64-dim vector + discrete opcode.
   - Opcodes (fixed palette of 4 for stability): 
     - **Bind**: Holographic binding (Fourier-based) of two vectors.
     - **Gate**: Selective routing/masking between tracks.
     - **Shift**: Pointwise arithmetic (add/subtract) or cyclic shift for sequencing.
     - **Recurse**: Push a new frame with predicted delta; enables composition (e.g., bind-then-gate as a subroutine).
   - Selection: Gumbel-Softmax over opcode logits for crisp, differentiable decisions (temperature annealed from 1.0 to 0.1 during training).
   - Update: Top frame predicts delta to itself + next opcode; if recurse, push new frame. Pop on low-confidence or stack full.

3. **Live Interpreter**:
   - The stack defines the transition function: Top opcode interprets the vector as params for track updates.
     - E.g., if "gate", vector encodes gating weights; apply as \( h_{t+1} = h_t \odot \sigma(W v) \), where v is stack vector.
     - Direct execution: No unrolling—ops act natively on tracks (e.g., "shift" adds vectors pointwise).
   - Input: Current token embedding + compressed global summary (z-vector from holography).
   - Output: New stack frame + A/B matrices for tracks.

4. **Holographic Persistence (Fault-Trace Buffer)**:
   - Fourier-based binding: For a state s, compute FFT(s) * exp(i * random_phase_key), then IFFT. Binds content, position, and errors.
   - Buffer: Global vector z (dim=512) accumulates top-100 fault traces (errors from failed predictions).
     - On error (high loss or mismatch): Bind error vector (predicted - actual) with key; add to z via superposition.
     - Eviction: Oldest by cosine similarity; if new error ~ old, reinforce rule instead of store.
     - Retrieval: Constant-time dot-product similarity; meta-stack queries z to avoid repeats.
   - Enables self-correction: Interpreter rewrites rules to minimize recurrence of bound faults.

5. **Cortex Controller**:
   - Tiny FFN (2 layers, dim=128, ~5M params): Takes input token + current top stack frame + z-summary; outputs opcode logits + vector delta.
   - Total params: ~50M (tracks + stack + cortex + embeddings).

### Forward Pass

For each token x_t:
1. Embed x_t (standard vocab embedding).
2. Cortex: Predict opcode and delta from (embed + top_stack + z).
3. Update stack: Apply delta; select opcode via Gumbel; if recurse, push.
4. Interpret: Use top frame to generate A/B for each track; evolve tracks in parallel.
5. Predict: Linear head from concatenated tracks → next token logits.
6. Error Check: If mismatch (e.g., token loss > threshold), bind fault to buffer; update z.
7. Output: Softmax for next token; cache z for efficiency.

Complexity: O(N * D) where D~256 (linear in sequence length, constant depth).

## Training

Staged curriculum to ensure stability; focus on toy tasks before scaling.

### Objectives
- Primary: Cross-entropy on next-token prediction.
- Meta: Binary "rule success" head (did update reduce future loss?); + KL-divergence between predicted/actual next stack for consistency.
- Density Regularizer: Penalize redundant ops (entropy on opcode distribution); + L1 on stack vectors for sparsity.
- Total Loss: CE + 0.1 * Meta + 0.01 * Reg.

### Phases
1. **Stage 0: Baseline ANA (Frozen Meta)**:
   - Train vanilla tracks + fixed cortex (no stack/recursion).
   - Data: Synthetic logic puzzles (Dyck languages, arithmetic chains, SCAN tasks).
   - Goal: Establish O(1) baseline; converge in 5 epochs on A100.

2. **Stage 1: Add Stack + Gumbel Routing**:
   - Unlock stack (depth=1 initially, ramp to 5).
   - Freeze holography; train on composition tasks (e.g., invent "multiply" from add/recurse).
   - Ablation: Disable recursion/opcodes to isolate gains.
   - Data: 1M synthetic sequences; mix 10% real text (GSM8K, C-Eval).
   - Goal: One-shot composition (e.g., 90% on unseen nested ops).

3. **Stage 2: Full Meta-Loss + Fault Traces**:
   - Unlock holography and self-correction.
   - Warm-start cortex on replay buffer of Stage 1 failures.
   - Data: Ramp to full WikiText/Code datasets; continual learning via fault queries.
   - Gradient Clipping: Norm <1.0; anneal Gumbel temp.
   - Goal: Emergent behaviors (e.g., self-invent subroutines); <25 perplexity.

Hardware: Single 8xA100 node; mixed precision (FP16 for tracks, BF16 for stack); gradient checkpointing.

### Evaluation
- **Standard**: Perplexity, recall accuracy.
- **Capability Tracker**: Probe mid-training: Solve unseen tasks (parity, theorem proving) post-meta-update; log trajectories.
- **Ablations**: Remove stack (should drop to Mamba-level); remove faults (slower convergence).
- Risks/Mitigation: Instability → Depth cap + reg; Overfitting → Synthetic pretrain.

## Implementation Notes
- Framework: PyTorch; use torch.fft for binding.
- Init: Orthogonal random keys; frozen random meta-state.
- Inference: Confidence-based lookahead (predict 2 tokens if >0.9); cache stack/z.
- Extensions: If stable, expand opcodes dynamically (meta-learn new ones).

This design is theoretically grounded (VSAs for capacity, meta-gradients for recursion) and empirically testable—start small, scale on success. If pursued, it could redefine adaptive AI beyond parametric tweaks.
